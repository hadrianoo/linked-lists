# Linked List

JavaScript implementation of a linked list data structure with full test coverage.

## Installation

npm install

## Run tests

npm test

## Methods

append, prepend, size, head, tail, at, pop, contains, findIndex, toString, insertAt, removeAt

## Built with

JavaScript, Jest

## What I learned

- How to traverse a linked list using pointer manipulation
- Why factory functions expose only necessary methods
- How to write tests before implementation (TDD approach)
